 🧾 BillPrint System (Java)

A Java console application** that simulates a real-world **shopping bill generator  
This project demonstrates how to handle user input, calculations, discount logic, and formatted console output in Java.  

---

 🚀 Features
- Collects customer details (name & phone number)  
- Accepts quantities for multiple grocery items  
- Calculates item-wise totals, overall total, discount, and final price
- Accepts cash payment and calculates balance  
- Breaks down the change into currency notes and coins 💵  
- Prints a well-formatted receipt 

---

 📂 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/YourUsername/BillPrintSystem.git
````

2. Navigate to the project folder:

   ```bash
   cd BillPrintSystem
   ```
3. Compile the Java file:

   ```bash
   javac BillPrint.java
   ```
4. Run the program:

   ```bash
   java BillPrint
   ```
